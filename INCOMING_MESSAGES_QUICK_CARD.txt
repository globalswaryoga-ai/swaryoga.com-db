# 🔄 Incoming Messages Not Showing - Quick Reference Card

## TL;DR (30 seconds)

```javascript
// Open DevTools Console and paste:
localStorage.clear()
sessionStorage.clear()
location.reload()

// Then:
// 1. Go to /admin/login
// 2. Enter admin credentials
// 3. Go to /admin/crm/whatsapp-meta
// 4. Send test message
// 5. Wait 10 seconds ✅
```

## Problem
Messages received by webhook but not showing in UI.

## Root Cause
**JWT token is invalid or expired** (90% of cases)

## Solution Ranking

| Priority | Fix | Success Rate |
|----------|-----|--------------|
| 1 | Clear storage + re-login | 85% |
| 2 | Hard refresh (Cmd/Ctrl+Shift+R) | 10% |
| 3 | Restart browser completely | 4% |
| 4 | Check server config | 1% |

## What's Actually Working
- ✅ Webhook receives messages
- ✅ Messages saved to database
- ✅ Conversations API exists
- ❌ Frontend JWT token invalid

## DevTools Checks

### 1. Check JWT Token
```
Application → Local Storage → admin_token
(copy value) → https://jwt.io/
Should show: ✅ Signature Verified + isAdmin:true + not expired
```

### 2. Check Polling
```
Network tab → Filter: "conversations"
Wait 10 seconds
Should show: GET requests every 10 seconds with 200 status
```

### 3. Check Errors
```
Console tab
Should show: ✅ No error messages related to auth or API
```

## If One of Above Fails

| Check | Fails | Fix |
|-------|-------|-----|
| Signature Verified ❌ | Token corrupted | Clear storage, re-login |
| isAdmin: true ❌ | Wrong user | Login with admin account |
| Not expired ❌ | Token old (7 days) | Re-login |
| No polling requests ❌ | Polling stopped | Reload page |
| 401 responses ❌ | JWT invalid | Clear storage, re-login |

## Last Resort
```bash
# Complete system reset:
1. Close all browser windows
2. Clear browser cache (Settings → Clear Data)
3. Restart browser
4. Go to /admin/login
5. Login again
6. Navigate to /admin/crm/whatsapp-meta
7. Send test message
```

## When to Escalate
- Webhook returns 500 error
- Database shows 0 messages
- After complete reset, still broken

## Tech Stack
- Backend: Next.js API Route `/api/whatsapp/webhook`
- Database: MongoDB `whatsappmessages` collection
- Frontend: React with polling (10s interval)
- Auth: JWT tokens (7 day expiry)

## Logs to Check
```
[WEBHOOK] Message upserted SUCCESS ✅ = backend works
401 Unauthorized ❌ = frontend token broken
GET conversations 200 ✅ = API works
GET conversations 401 ❌ = auth broken
```
