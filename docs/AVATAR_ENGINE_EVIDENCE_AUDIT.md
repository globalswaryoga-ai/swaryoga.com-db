# Avatar Engine Evidence Audit

## Summary

The repository contains useful avatar data models, studio interfaces, a consent-aware Bunny SQL render queue, Edge TTS speech preparation, and a worker protocol. Avatar Studio's Twins Library lists saved consent-verified avatar identity profiles and can select one for render setup; these records are not trained or generated twins. The end-to-end neural video renderer, GPU host, installed model weights, and commercial rights for specific model checkpoints are not verified by repository code or configuration alone.

Do not treat database registry rows, seeded profile records, UI labels, or a queued job as proof of model installation, licensing, training, validation, or completed video generation.

## Corrected operational interpretation

- The Contabo web/API server is not evidence of an NVIDIA GPU inference host.
- The 3D Body Prototype is a generic, measurement-based mesh, not a Mohan Sir likeness. Changing hair/clothes and real-time face/audio tracking are not implemented.
- `ready_for_worker` means queued for a configured worker, not rendered.
- The recorded-audio upload path establishes only an authenticated upload and queue input. It does not establish Bunny token enforcement, phoneme alignment, GPU inference, or a talking video.
- The sampled local promotional clips show composited/promotional imagery; source motion, identity provenance, and authorization are not established, so they are not accepted without further review.
- `completed` is valid only after the worker reports a real Bunny-hosted output from the configured inference pipeline.
- A source/anchor video, still-image mux, sample clip, or imported video is not a generated render.
- The legacy local scripts named `run_60s_acceptance_milestone.py`, `run_acceptance_test_pipeline.py`, and `compile_and_upload_acceptance_video.py` only looped/muxed video or compiled static frames. They have been replaced with fail-closed notices; outputs from their previous implementations must not be treated as neural inference.
- Consent records establish an application-side authorization assertion; they are not identity verification or legal advice.
- A model is not commercially approved merely because a database row says `commercial_permitted = 1`.
- The avatar-library API is Super Admin-only because its legacy output table has no tenant-ownership column. Imported URLs remain unverified source metadata and are not generated renders.
- The legacy Colab/Kaggle avatar notebooks and their generators are retired. They do not provide a verified inference or upload path and must not be used to publish avatar outputs.
