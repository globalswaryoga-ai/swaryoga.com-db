# 🎯 FINAL SUMMARY - Cart, Checkout & Webhook Setup

## 🔗 WEBHOOK URL (COPY & PASTE THIS)

```
https://swaryoga.com/api/payments/cashfree/webhook
```

**Where to use it:**
1. Go to: https://dashboard.cashfree.com
2. Settings → Webhook Configuration
3. Click "Add Webhook"
4. Paste the URL above
5. Enable events: PAYMENT_SUCCESS, PAYMENT_FAILED, PAYMENT_CANCELLED
6. Save

## 🚀 How to Use

### Display Products
```tsx
import ProductCard from '@/components/ProductCard';

<ProductCard
  id="yoga-101"
  name="Yoga Basics"
  description="Learn yoga fundamentals"
  price={999}
  duration="8 weeks"
  level="Beginner"
  instructorName="Raj Kumar"
  rating={4.8}
/>
```

### Use Cart Hook
```tsx
import { useCart } from '@/lib/context/CartContext';

const { items, total, addToCart } = useCart();
<div>Cart Items: {items.length} | Total: ₹{total}</div>
```

### Add to Cart Button
```tsx
<AddToCartButton
  id="course-123"
  name="Advanced Yoga"
  price={1999}
/>
```
